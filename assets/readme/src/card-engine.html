VisiGrid
CLI and headless

One engine, three ways to run it.

The desktop app, the vgrid CLI and headless mode share the same Rust formula engine. A formula computes the same in all three, with no spreadsheet app in the pipeline.

$ cat invoices.csv | vgrid calc "=SUM(D:D)" --from csv --headers
45900
